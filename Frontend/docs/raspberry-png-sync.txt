FaDO: 자동 저장한 표정 PNG를 라즈베리파이와 OLED에 반영하기

현재 코드 상태
- 프론트: 저장/선택 시 Java에 PNG를 전송합니다.
- Java: PNG를 uploads/expressions에 저장합니다.
- RaspberryClient: 선택 ID를 라파의 POST /expression으로 보냅니다.
- 라파: 현재 happy일 때만 고정 JPEG를 출력합니다.

목표 흐름
표정 저장: React → Java PNG 저장 → 라파 PNG 저장 → 성공 응답
표정 선택: 위 PNG 저장 완료 → Java 선택 ID 전송 → 라파에서 ID.png를 OLED에 출력
표정 삭제: React → Java → 라파 PNG 삭제 → Java PNG 삭제 → 브라우저 목록 삭제

이 문서는 적용할 코드 예제입니다. 실제 Backend/RPiServer/RaspberryPi 파일은 수정하지 않았습니다.
기존 업로드/삭제 API에 아래 전달 처리를 추가하면 프론트 변경은 필요 없습니다.

1. Java: RaspberryClient.java에 PNG 전달/삭제 메서드 추가

현재 RaspberryClient에 있는 client, ByteArrayResource, HttpHeaders, HttpEntity,
MultiValueMap, LinkedMultiValueMap, MediaType를 그대로 사용합니다.
추가 import:
import org.springframework.web.reactive.function.client.WebClientException;

----- RaspberryClient 클래스 내부에 추가 -----
public void uploadExpressionImage(String expressionId, String name, byte[] pngBytes) {
    ByteArrayResource resource = new ByteArrayResource(pngBytes) {
        @Override
        public String getFilename() {
            return expressionId + ".png";
        }
    };

    HttpHeaders headers = new HttpHeaders();
    headers.setContentType(MediaType.IMAGE_PNG);

    MultiValueMap<String, Object> parts = new LinkedMultiValueMap<>();
    parts.add("expressionId", expressionId);
    parts.add("name", name);
    parts.add("file", new HttpEntity<>(resource, headers));

    try {
        client.post()
                .uri("/expression/image")
                .contentType(MediaType.MULTIPART_FORM_DATA)
                .bodyValue(parts)
                .retrieve()
                .toBodilessEntity()
                .block();
    } catch (WebClientException error) {
        throw new ResponseStatusException(
                HttpStatus.BAD_GATEWAY, "라파 PNG 저장에 실패했습니다.", error
        );
    }
}

public void deleteExpressionImage(String expressionId) {
    try {
        client.delete()
                .uri(builder -> builder.path("/expression/image")
                        .queryParam("expressionId", expressionId).build())
                .retrieve()
                .toBodilessEntity()
                .block();
    } catch (WebClientException error) {
        throw new ResponseStatusException(
                HttpStatus.BAD_GATEWAY, "라파 PNG 삭제에 실패했습니다.", error
        );
    }
}

def show_image(image_path=IMAGE_PATH):
    with Image.open(image_path) as raw_image:
        resized_image = ImageOps.contain(raw_image, (WIDTH, HEIGHT))
        canvas = Image.new("1", (WIDTH, HEIGHT), 0)
        paste_x = (WIDTH - resized_image.width) // 2
        paste_y = (HEIGHT - resized_image.height) // 2
        canvas.paste(resized_image.convert("1"), (paste_x, paste_y))
        oled.image(canvas)
        oled.show()

현재 app = FastAPI(), yolo router 등록, /health, /gif는 유지합니다.
기존 ExpressionRequest 클래스와 POST /expression 함수는 제거한 뒤 아래로 교체합니다.

아래 코드는 app, BaseModel, ImgTest가 현재 main.py에서 이미 정의/import된 상태를 전제로 합니다.

----- RPiServer/main.py의 표정 처리 코드 -----
EXPRESSION_DIR = Path(__file__).resolve().parent / "expressions"
expression_lock = Lock()
MAX_PNG_BYTES = 1024 * 1024


def expression_path(expression_id: str) -> Path:
    if not re.fullmatch(r"[a-zA-Z0-9-]{1,100}", expression_id):
        raise HTTPException(status_code=400, detail="올바르지 않은 표정 ID")
    return EXPRESSION_DIR / f"{expression_id}.png"


class ExpressionRequest(BaseModel):
    expressionId: str


@app.post("/expression/image")
def upload_expression_image(
    expressionId: str = Form(...),
    name: str = Form(...),
    file: UploadFile = File(...),
):
    target = expression_path(expressionId)
    if not name.strip() or len(name) > 100:
        raise HTTPException(status_code=400, detail="표정 이름을 확인해주세요")
    data = file.file.read(MAX_PNG_BYTES + 1)
    if not data or len(data) > MAX_PNG_BYTES:
        raise HTTPException(status_code=413, detail="1MB 이하 PNG가 필요합니다")

    try:
        output = BytesIO()
        with Image.open(BytesIO(data)) as raw:
            if raw.format != "PNG" or raw.size != (128, 64):
                raise HTTPException(status_code=400, detail="128 x 64 PNG만 지원합니다")
            with raw.convert("1") as image:
                image.save(output, format="PNG")
        png_bytes = output.getvalue()
    except (UnidentifiedImageError, OSError, ValueError, Image.DecompressionBombError) as error:
        raise HTTPException(status_code=400, detail="올바르지 않은 PNG") from error

    with expression_lock:
        EXPRESSION_DIR.mkdir(parents=True, exist_ok=True)
        target.write_bytes(png_bytes)
    return {"expressionId": expressionId, "name": name.strip(), "saved": True}


@app.post("/expression")
def expression(request: ExpressionRequest):
    target = expression_path(request.expressionId)
    with expression_lock:
        if not target.is_file():
            raise HTTPException(status_code=404, detail="저장된 표정 PNG가 없습니다")
        ImgTest.show_image(target)
    return {"expressionId": request.expressionId, "displayed": True}


@app.delete("/expression/image", status_code=204)
def delete_expression_image(expressionId: str):
    target = expression_path(expressionId)
    with expression_lock:
        if target.is_dir():
            raise HTTPException(status_code=409, detail="PNG 경로에 폴더가 있습니다")
        target.unlink(missing_ok=True)
    return Response(status_code=204)
----- 끝 -----

라파 저장 위치: RPiServer/expressions/<표정ID>.png
업로드 성공은 파일 저장을 뜻합니다. OLED 출력은 POST /expression이 수행합니다.
프론트 선택 동작은 이미 PNG 업로드를 기다린 뒤 이 선택 요청을 보내도록 되어 있습니다.
편집 저장만 하면 파일이 저장되고, 해당 표정을 선택하면 새 그림을 표시합니다.
파일을 삭제해도 OLED에 남아 있는 픽셀은 자동으로 바뀌지 않습니다.
삭제 후 OLED도 바꾸려면 기본 표정을 선택하거나 별도의 화면 지우기를 호출해야 합니다.

5. 실행 및 확인

requirements_raspberryPi.txt에는 fastapi, python-multipart, pillow가 이미 포함되어 있습니다.
라파의 프로젝트 루트에서 가상환경을 활성화한 뒤 실행:
python -m uvicorn RPiServer.main:app --host 0.0.0.0 --port 8000 --workers 1

하드웨어를 하나의 프로세스에서 관리하도록 workers는 1로 둡니다.
Java application.properties의 Raspberry.base-url은 라파 API 주소와 포트를 지정합니다.
예: Raspberry.base-url=http://<라파주소>:8000
이미 Nginx로 연결 중이라면 그 프록시가 제공하는 주소를 사용합니다.

확인 순서
1. 프론트에서 기본 표정을 선택합니다.
2. Java uploads/expressions/<ID>.png와 라파 RPiServer/expressions/<ID>.png를 확인합니다.
3. OLED가 그 PNG로 변경되는지 확인합니다.
4. 새 표정을 편집 저장한 뒤 선택해 출력하고, 삭제 시 양쪽 PNG가 지워지는지 확인합니다.

이 문서의 Python 표정 처리/출력 코드는 문법만 검증했으며,
실제 Java → 라파 통신과 OLED 하드웨어 동작은 라파에서 확인해야 합니다.
