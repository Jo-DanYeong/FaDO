FaDO 표정 PNG 업로드: Java 백엔드 수신 예제

프론트 사용법
1. 기본·사용자 표정을 선택하면 PNG를 자동 저장한 뒤 ID 선택 명령을 전송합니다.
2. 직접 그린 표정은 편집기의 '표정 저장하기'를 누르면 브라우저와 서버에 저장합니다.
3. 기존 사용자 표정을 편집 저장해도 같은 ID의 서버 PNG를 자동 갱신합니다.
4. 스튜디오의 아래쪽 화살표(PNG 저장)는 기존처럼 내 컴퓨터에 다운로드합니다.
별도 업로드 버튼은 없습니다. 앱 시작 시 일괄 업로드나 데모 자동 업로드는 하지 않습니다.
서버 저장에 실패한 편집 결과는 브라우저에 보관하며, 다시 저장하거나 선택해서 재시도합니다.
선택·편집 저장·삭제는 하나의 요청 대기열에서 순서대로 실행합니다.

프론트는 원본 bitmap으로 128 x 64 PNG를 메모리에서 만듭니다.
배경은 검정, 켜진 픽셀은 흰색이며 미리보기 밝기/CSS 색상은 적용하지 않습니다.
파일을 디스크에 먼저 다운로드하거나 다시 선택할 필요는 없습니다.

요청 계약
POST /api/v1/expression/image
Content-Type: multipart/form-data; boundary=브라우저가_자동_지정

필드명        값
expressionId  happy 또는 custom-... 등의 표정 ID
name          표정 이름
file          image/png 파일, 예: fado-happy.png

삭제: DELETE /api/v1/expression/image?expressionId=custom-...
삭제 요청은 본문 없이 ID를 쿼리로 보냅니다. 파일이 없어도 204로 성공 처리합니다.
기존 Java 삭제 메서드만 고칠 때는 같은 폴더의 png-delete-backend.txt를 참고하세요.

기존 POST /api/v1/expression JSON API는 표정 선택용으로 유지됩니다.
이미지 업로드 API는 별도로 추가합니다. @RequestBody DTO 대신 파일 파트를 받습니다.

아래 코드를 백엔드에 ExpressionImageController.java로 추가하세요.
패키지는 현재 프로젝트의 backend.server.RaspberryPi.API에 맞췄습니다.
이 TXT는 참고용이며 기존 백엔드 파일은 수정하지 않았습니다.

----- ExpressionImageController.java -----
package backend.server.RaspberryPi.API;

import org.springframework.http.HttpStatus;
import org.springframework.http.MediaType;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;
import org.springframework.web.server.ResponseStatusException;

import javax.imageio.ImageIO;
import javax.imageio.ImageReader;
import javax.imageio.stream.ImageInputStream;
import java.awt.image.BufferedImage;
import java.io.IOException;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Iterator;

@RestController
@RequestMapping("/api/v1/expression")
public class ExpressionImageController {
    private final Path storageDirectory = Path.of("uploads", "expressions")
            .toAbsolutePath().normalize();

    @PostMapping(value = "/image", consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
    public ResponseEntity<ExpressionImageResponse> uploadImage(
            @RequestParam("expressionId") String expressionId,
            @RequestParam("name") String name,
            @RequestPart("file") MultipartFile file
    ) throws IOException {
        // 서버 저장 경로에는 클라이언트가 보낸 파일명을 사용하지 않습니다.
        if (!expressionId.matches("[a-zA-Z0-9-]{1,100}")) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "올바르지 않은 표정 ID입니다.");
        }
        if (name.isBlank() || name.length() > 100) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "표정 이름을 확인해주세요.");
        }
        if (file.isEmpty() || file.getSize() > 1024 * 1024) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "1MB 이하의 PNG 파일이 필요합니다.");
        }

        BufferedImage image;
        try (InputStream stream = file.getInputStream();
             ImageInputStream input = ImageIO.createImageInputStream(stream)) {
            if (input == null) {
                throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "이미지를 읽을 수 없습니다.");
            }
            Iterator<ImageReader> readers = ImageIO.getImageReaders(input);
            if (!readers.hasNext()) {
                throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "이미지 파일이 아닙니다.");
            }
            ImageReader reader = readers.next();
            try {
                reader.setInput(input);
                if (!"png".equalsIgnoreCase(reader.getFormatName())
                        || reader.getWidth(0) != 128 || reader.getHeight(0) != 64) {
                    throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "128 x 64 PNG만 업로드할 수 있습니다.");
                }
                image = reader.read(0);
            } finally {
                reader.dispose();
            }
        }

        Files.createDirectories(storageDirectory);
        String filename = expressionId + ".png";
        Path target = storageDirectory.resolve(filename);
        if (!ImageIO.write(image, "png", target.toFile())) {
            throw new IOException("PNG 파일을 저장하지 못했습니다.");
        }

        return ResponseEntity.ok(new ExpressionImageResponse(
                expressionId, name.trim(), filename, 128, 64
        ));
    }

    @DeleteMapping("/image")
    public ResponseEntity<Void> deleteImage(
            @RequestParam("expressionId") String expressionId
    ) throws IOException {
        if (!expressionId.matches("[a-zA-Z0-9-]{1,100}")) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "올바르지 않은 표정 ID입니다.");
        }
        Path target = storageDirectory.resolve(expressionId + ".png").normalize();
        if (!target.getParent().equals(storageDirectory)) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "올바르지 않은 파일 경로입니다.");
        }
        if (Files.isDirectory(target)) {
            throw new ResponseStatusException(HttpStatus.CONFLICT, "PNG 파일 경로에 폴더가 있습니다.");
        }
        Files.deleteIfExists(target);
        return ResponseEntity.noContent().build();
    }

    public record ExpressionImageResponse(
            String expressionId, String name, String filename, int width, int height
    ) {}
}
----- 끝 -----

application.properties에 업로드 제한을 명시할 수 있습니다.
spring.servlet.multipart.max-file-size=1MB
spring.servlet.multipart.max-request-size=2MB

저장 위치: Java 프로세스 실행 폴더 기준 uploads/expressions/<표정ID>.png
같은 ID를 다시 전송하면 해당 PNG를 덮어씁니다. 이름은 응답에만 포함하며 DB에는 저장하지 않습니다.
삭제는 해당 ID의 PNG 파일 하나만 대상으로 하며 저장 폴더는 유지합니다.
이 예제의 성공은 Java 서버에 PNG가 저장됐다는 뜻입니다.
Raspberry Pi에 재전송하거나 OLED에 표시하는 코드는 RaspberryClient 등에 별도로 연결하세요.

개발 환경: http://127.0.0.1:3000 → /api 프록시 → http://127.0.0.1:8080
프록시 대상은 프론트의 webpack.config.dev.js에서 바꿀 수 있습니다.
이 컨트롤러를 추가하기 전에는 PNG 요청이 404/405로 실패할 수 있습니다.
