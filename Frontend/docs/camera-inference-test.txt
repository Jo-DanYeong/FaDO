노트북 카메라 → Java → 라파 인식 모델 테스트

라파 카메라는 필요하지 않습니다.
노트북 브라우저가 한 장을 캡처하고, 라파는 이미지를 받아 모델 추론만 수행합니다.

먼저 Java 요청 경로 수정
파일: Backend/src/main/java/backend/server/RaspberryPi/RaspberryClient.java
predict() 메서드의 아래 한 줄을 바꾸세요.

변경 전:
    .uri("/predict")

변경 후:
    .uri("/yolo/predict")  

근거: 현재 RPiServer/yolo_api.py는 APIRouter(prefix="/yolo")에
@router.post("/predict")를 등록하므로 최종 경로가 /yolo/predict입니다.
다른 uploadExpressionImage(), deleteExpressionImage(), sendExpression()의 경로는 유지합니다.
Nginx에서 별도 경로 재작성을 사용한다면 실제 외부 제공 경로에 맞춰야 합니다.
이 TXT는 수정 예제이며 실제 Java 파일을 직접 수정하지 않았습니다.

Java application.properties의 Raspberry.base-url은 실행 중인 라파 API 주소와 포트입니다.
프론트 설정 화면에 적은 주소는 이 값을 바꾸지 않습니다.
예: Raspberry.base-url=http://<라파주소>:8000
Nginx로 서비스 중이라면 Nginx가 제공하는 주소를 사용합니다.

테스트 순서
1. 라파의 추론 서버와 Java 백엔드를 실행합니다. Java 코드를 바꿨으면 재시작합니다.
2. 프론트 http://127.0.0.1:3000/#settings 를 엽니다.
3. '카메라 켜기'를 누르고 브라우저의 카메라 접근을 허용합니다.
4. 노트북 카메라 영상이 보이면 '카메라 인식 테스트'를 누릅니다.
5. 버튼을 누를 때 이미지 한 장만 전송하며 실제 클래스 이름과 신뢰도를 표시합니다.
6. 테스트 후 '카메라 끄기'를 누릅니다.

요청 흐름
브라우저 캡처: 최대 긴 변 640px의 JPEG, 브라우저 미리보기의 좌우 반전은 적용하지 않음
브라우저 → Java: POST /api/v1/detect, multipart 필드 file
Java → 라파: POST /yolo/predict, multipart 필드 file
Java → 브라우저: { "detections": [{ "className": "person", "confidence": 0.96, "box": [...] }] }

카메라를 켜는 것만으로 이미지를 보내지 않습니다.
인식 버튼을 누를 때만 Java와 라파에 전송하며 주기적 자동 업로드는 하지 않습니다.
카메라를 끄거나 설정 화면을 떠나면 카메라 트랙을 종료하고 대기 요청을 취소합니다.
이미 서버에 전달된 이미지는 취소로 되돌릴 수 없으며 서버가 추론을 계속할 수 있습니다.
결과와 캡처 이미지는 프론트 localStorage나 파일에 저장하지 않습니다.

현재 모델의 범위
RPiServer/models/yolo26n_ncnn_model/metadata.yaml은 task: detect, COCO 클래스입니다.
person, chair, laptop 등은 현재 모델이 반환할 수 있는 정상 결과입니다.
happy, sad, angry 같은 표정 분류를 시험하려면 표정용으로 학습한 모델과 서버 응답을 연결해야 합니다.
이 테스트 결과로 OLED 표정을 자동 선택하지는 않습니다.

오류 확인
- 카메라 권한 오류: 브라우저 및 Windows의 카메라 접근 허용을 확인합니다.
- 영상 준비 오류: 미리보기에 영상이 나타난 뒤 다시 테스트합니다.
- 404: Java /api/v1/detect 또는 라파 /yolo/predict 경로를 확인합니다.
- 502/503: Java 터미널에서 라파 연결 실패, 원격 응답 코드, 모델 로딩 오류를 확인합니다.
- 인식 결과 없음: 연결은 성공했지만 모델이 대상을 찾지 못한 것입니다. 사람/물체가 보이도록 구도를 바꿉니다.

검증 범위
프론트 자동 테스트는 가짜 카메라·JPEG·API 응답을 사용합니다.
실제 노트북 카메라 권한, 라파 통신, 모델 추론은 위 순서로 직접 확인해야 합니다.
