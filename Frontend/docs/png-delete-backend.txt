FaDO 표정 삭제 시 서버 PNG도 삭제하기

프론트 요청
DELETE /api/v1/expression/image?expressionId=custom-...
본문과 Content-Type 헤더는 보내지 않습니다.

현재 Java의 ExpressionImageController.deleteImage()를 아래 코드로 교체하세요.
storageDirectory 필드는 업로드 메서드와 같은 것을 사용합니다.
프론트 코드만 수정된 상태이므로 실제 서버 파일 삭제에는 이 Java 수정도 필요합니다.

필요한 import
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.http.ResponseEntity;
import org.springframework.http.HttpStatus;
import org.springframework.web.server.ResponseStatusException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.io.IOException;

----- 기존 deleteImage 메서드 교체 -----
@DeleteMapping("/image")
public ResponseEntity<Void> deleteImage(
        @RequestParam("expressionId") String expressionId
) throws IOException {
    if (!expressionId.matches("[a-zA-Z0-9-]{1,100}")) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "올바르지 않은 표정 ID입니다.");
    }

    Path target = storageDirectory.resolve(expressionId + ".png").normalize();
    if (!target.getParent().equals(storageDirectory)) {
        throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "올바르지 않은 파일 경로입니다.");
    }
    if (Files.isDirectory(target)) {
        throw new ResponseStatusException(HttpStatus.CONFLICT, "PNG 파일 경로에 폴더가 있습니다.");
    }

    Files.deleteIfExists(target);
    return ResponseEntity.noContent().build();
}
----- 끝 -----

기존 코드에서 고쳐야 하는 부분
- Files.delete(storageDirectory)는 PNG가 아닌 저장 폴더를 삭제하려는 코드입니다.
- 삭제 대상은 uploads/expressions/<표정ID>.png입니다.
- Files.deleteIfExists(target)는 해당 파일만 삭제합니다. 폴더 전체를 재귀 삭제하지 않습니다.
- 업로드한 적이 없어 파일이 없거나 이미 지운 파일이어도 204로 성공 처리합니다.
- 권한 부족 등의 실제 파일 삭제 오류는 성공으로 처리하지 않습니다.

프론트 동작
- 서버 삭제 응답이 2xx일 때만 reducer로 표정과 localStorage 데이터를 삭제합니다.
- 서버 오류나 네트워크 오류면 브라우저 표정을 보존하고 알림을 띄웁니다.
- 선택·편집 저장 시 PNG를 자동 업로드하며, 삭제는 앞선 업로드·선택 뒤에 순서대로 실행합니다.
- 삭제 중인 표정의 선택·편집과 중복 삭제는 막습니다.
- 사용자 표정의 삭제 버튼에 연결되어 있습니다. 기본 표정은 기존대로 목록에서 삭제하지 않습니다.

이 기능은 Java 서버의 PNG를 삭제합니다.
사용자가 별도로 다운로드한 PC의 PNG나 Raspberry Pi에 복사한 파일은 삭제하지 않습니다.
